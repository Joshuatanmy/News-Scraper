# News-Scraper
Web Scraper project. Goal to scrape news sites for recent news articles and save information to database. Using filtering and keyword search to identify relevant articles of different topics.


Project AIM: scrape a selected list of news sites daily for news articles, then sort and store the article information for analysis.

Project Scope: 
Build a web scraper that scrapes a given list of websites for news articles.
Clean and sort data.
Pipe data to noSQL mongoDB database.
Build data visualisations that take data stored to be analysed.

Future project expansion:
news articles can be fed through text analysis NN to identify topics of each news article used to classify articles by topic.
ML model used to predict visibility/traffic of an article based on keywords, topics, or any other factors identified.
